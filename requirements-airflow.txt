# The Airflow environment, the fourth and last.
#
# Installed against the official constraints file — see the venv-airflow target
# in the Makefile. That is not over-caution: Airflow has around two hundred
# transitive dependencies, and without pins the resolver assembles a combination
# nobody has ever tested. The official file describes exactly the one this
# version of Airflow was tested on.
#
# The URL of that file is put together in the Makefile, because it depends on
# two things at once: the Airflow version and the interpreter version. Nailing
# it down here as a string would break the install for everyone on a different
# Python, and that is most people. The Airflow version itself lives here, in
# one place, and the Makefile reads it from this file.
#
# The postgres extra is there for the metadata database driver: it lives in a
# second database inside the same container as the warehouse, and there is no
# separate service for it.
apache-airflow[postgres]==3.3.1
