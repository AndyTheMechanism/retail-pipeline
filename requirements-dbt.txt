# The dbt environment is separate from the generator's on purpose.
#
# The generator talks to the database through psycopg3, and the dbt adapter
# only speaks psycopg2. Both drivers can be brought into one environment, but
# then a failed dbt install breaks make seed too — and the generator has to
# work on its own. There are four environments in all: the generator, dbt, the
# reconciliation and Airflow. The DAG calls dbt as a subprocess, and the
# interface between them is an exit code, not a shared site-packages.

# The lower bound matters more than the upper one here, which is unusual — a pin
# is normally held from above, to keep a breaking update out.
#
# dbt-core 1.11 installs on Python 3.14 without a single error, then falls over
# on the first command: it pins mashumaro<3.15, and on 3.14 that cannot build
# its unpacker and takes dbt down with UnserializableField. Support arrived in
# mashumaro 3.17, and only 1.12 allows it.
#
# Established by installing, not by reading a list of supported versions: on
# 1.11.13 `dbt --version` fails, on 1.12.2 it passes.
dbt-core>=1.12,<1.13
dbt-postgres>=1.11,<1.12
